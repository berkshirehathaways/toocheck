# [#8] 후보 비교표 페이지

## 목적
한 지역구 내 후보를 가로 비교 (또는 모바일에선 transpose된 카드)로 한 눈에 본다.

> 참조: PRD §6.5, §16.4

## 산출물

```
app/(public)/districts/[districtId]/compare/
└── page.tsx

components/domain/
├── CompareTable.tsx               # ≥768px: 가로 비교표
├── CompareCardsMobile.tsx         # <768px: transpose 카드
└── (재사용) SortSelector

lib/
└── compare-rank.ts                 # 정렬 + 분위 계산
```

## 비교 항목 (PRD §6.5 그대로)
열 순서:
1. 기호
2. 후보명
3. 정당
4. 전과기록 공개 여부 (배지)
5. 체납기록 공개 여부 (배지)
6. 재산신고액 (formatKrwShort)
7. 재산 구성 요약 (부동산 / 예금 / 증권 %)
8. 병역 공개정보 (raw text 요약)
9. 공약 수
10. 공약 구체성 평균 (소수 1자리)
11. 원문 링크 (`<SourceLink>`)

## 정렬 옵션 (PRD §6.5)
- 기호순 (default)
- 전과기록 공개 여부 (있음 우선)
- 체납기록 공개 여부 (있음 우선)
- 재산신고액 (높은 순 / 낮은 순)
- 공약 구체성 (높은 순)

URL query `?sort=` 동기화.

## 모바일 UX

**권장: Transpose** — 한 후보 = 한 카드, 11개 항목을 세로 스택. 가로 스크롤은 항목 비교 의미를 약화시킴.

```
┌─────────────────────────┐
│ 기호 1 · 김ㅇㅇ · 정당 A │
│─────────────────────────│
│ 전과기록   공개자료 없음  │
│ 체납기록   공개자료 있음  │
│ 재산       12.3억         │
│ ...                      │
└─────────────────────────┘
```

좌우 스와이프로 다음 후보 카드 (mobile only).

## 데이터 흐름
- 서버 컴포넌트에서 `getCompareData(districtId)` (loader)
- 분위 계산은 District 내 reviewed 후보 대상

## needs_check 후보
- 비교표에서 별도 행 또는 카드로 표시 (`자료 확인 중`)
- 정렬에서는 항상 마지막 위치

## 인쇄 (`@media print`)
- 비교표 사용자가 인쇄해서 들고 갈 수 있도록
- A4 가로 / 4명 기준 1페이지

## 수용 기준
- [ ] 모든 후보가 같은 항목으로 표시 (PRD §16.4)
- [ ] 정렬 기준 라벨 금지어 0건
- [ ] needs_check 후보는 `자료 확인 중` 으로 표시 + 정렬 시 항상 마지막
- [ ] 모바일 320px 폭에서 가독성 확보
- [ ] 인쇄 시 4명 기준 1페이지에 들어감
