# [#0] 사람 결정 필요 사항 — 일괄 트래커

12개 작업 이슈(#1~#12)에 흩어져 있던 `🚨 사람 결정 필요` 항목 86개를 카테고리별로 묶고, **각 항목별 결정해야 할 것 / 선택지 / 추천안 / 추천 근거 / 영향 범위**를 명시한 의사결정 트래커.

> 본 문서의 목표: **결정 비용을 최소화**한다. 정보가 충분한 항목은 추천안(▶)을 그대로 채택하면 되도록 근거를 명시했고, 추가 정보·취향이 필요한 항목은 별도 사람 결정으로 분리했다.

## 사용 방법

1. 아래 **⭐ 핵심 우선순위 6개**부터 검토 — 나머지에 cascade
2. 카테고리별 상세 항목에서 추천안(▶)이 적절하면 `**결정:**` 라인에 `채택` 기입, 아니면 다른 선택지 + 이유 메모
3. PRD 보강이 필요한 결정은 `docs/prd-addendum.md`에 누적
4. **착수 권장 순서**: A·B → C·D → E·F·G

## ⭐ 핵심 우선순위 6개 (cascade 영향)

이 6개만 결정하면 나머지 80개는 권장안 일괄 채택 가능. 비즈니스·법무 검토가 필요한 항목들.

1. **[A1](#a1)** 서비스 명칭 표기
2. **[A2](#a2)** 운영주체 표기
