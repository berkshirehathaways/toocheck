## 2. 면책 문구 (Phase A3)

**페이지 푸터 (긴 버전 / 4요소 명시):**

> 본 서비스는 공개자료를 바탕으로 후보자 정보를 비교해 보여줍니다. 후보 지지·반대 의도가 없습니다. 자료에 오류가 있다면 정정 요청을 보내주세요.

**공유 카드 (짧은 버전 / 워터마크):**

> 공개자료 기반 비당파적 비교 도구입니다. 오류는 정정 요청을 보내주세요.

## 3. 비당파성 정책 (Phase B)

- mock 시드의 District/정당명은 **모두 가상** (`샘플 시 가나구청장`, `정당 A·B·C`).
- 공유 카드는 **기호만 노출** (후보명·정당명 모두 비표시).
- 금지어 매칭은 **부분 일치** (PRD §17 + §6.3 + §10 + §11 = 약 21개 기본).

## 4. 디자인 토큰 (Phase E2)

| 토큰 | hex | 용도 |
|---|---|---|
| `signal.info` | `#3b6fb0` | 정상/완료 신호 |
| `signal.check` | `#a86b1f` | 확인 필요 (앰버) |
| `signal.attention` | `#7c2b2b` | 강한 주의 (burgundy) |

- 전체 톤: 그레이스케일 + 위 신호색만 채도 사용
- 모바일 본문 기본 폰트 크기: **15px**
- Pretendard self-host
- Light only (mock 단계, dark mode 미지원)

> 디자이너 검토는 정식 베타 단계로 연기. WCAG AA 컨트라스트 검증은 베타 진입 전 필수 항목.
